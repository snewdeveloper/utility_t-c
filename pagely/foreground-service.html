FOREGROUND_SERVICE_DATA_SYNC

Pagely — PDF Tools & Editor  ·  com.sknewdev.folio

Pagely declares FOREGROUND_SERVICE_DATA_SYNC for one purpose: a document job the user has started must be able to finish after they leave the screen. The task category is local processing. No network access is involved.

What the service does

When the user runs a tool — merging, compressing, converting, text recognition, watermarking and so on — the work runs in a WorkManager worker wrapped in a foreground service, with an ongoing notification showing progress and offering cancellation.

Without it, Android would stop the job the moment the user switched away, and a large document would be lost halfway through. All processing is local to the device; the app has no server and uploads nothing.

What the recording shows

  1. The user opens Pagely and chooses the PDF → Images tool.
  2. They pick a 500-page PDF from their own storage and start the export.
  3. They leave the app immediately, returning to the home screen.
  4. The notification shade shows the ongoing foreground-service notification with live progress, while the app is in the background.
  5. The job completes in the background and a completion notification appears. All 500 images were written.

If the recording does not play in your browser, the file is served directly at foreground-service-demo.mp4 (H.264 MP4).
